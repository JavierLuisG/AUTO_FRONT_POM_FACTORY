## HU 1: Generación de Reconocimientos

**Como** integrante de la comunidad Sofkiana    
**Quiero** crear reconocimientos para mis compañeros    
**Para** transformar nuestra identidad en Kudos tangibles que celebren sus logros.

Criterios de aceptación:

- El usuario debe poder **seleccionar un remitente** desde la lista disponible.
- El usuario debe poder **seleccionar un destinatario** desde la lista disponible.
- El sistema debe permitir **seleccionar una categoría de reconocimiento** (ej. Innovation).
- El usuario debe poder **escribir un mensaje de felicitación personalizado**.
- Al enviar el reconocimiento, el sistema debe **confirmar visualmente que el reconocimiento fue enviado exitosamente**.

## HU 2: Visualización de Kudos

**Como** integrante de la comunidad Sofkiana    
**Quiero** explorar la sección de Kudos  
**Para** visualizar y celebrar los reconocimientos otorgados en la comunidad.

Criterios de aceptación:

- El sistema debe **listar los reconocimientos generados en la plataforma**.
- Cada reconocimiento debe mostrar:
    - DE
    - PARA
    - CATEGORIA
    - MENSAJE
    - FECHA
- El reconocimiento recién creado debe **aparecer en la lista de Kudos**.
